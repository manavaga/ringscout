# RingScout Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public GitHub issues, pull requests, or discussions.

Use GitHub's private vulnerability reporting feature on `https://github.com/manavaga/ringscout` if enabled, or email **agarwalmanav91@gmail.com** with the subject `"RingScout Security"`.

## What to include

- A clear description of the issue and its potential impact;
- Affected endpoint, component, or version;
- Minimal reproducible steps that do not access or expose third-party data;
- Suggested mitigation, if any.

Never include real customer data, private call audio, secrets, API keys, or payment credentials in a report.

## Responsible testing

Do not disrupt the service, conduct denial-of-service testing, access data belonging to other users, or trigger unsolicited PSTN calls to third-party businesses. Allow a reasonable window to investigate and remediate before public disclosure.
